03 · Pricing & Tiers

Seat price ≠ real cost

Token volume and context length drive spend more than the subscription line does. Click a tier to expand what it adds.

What actually costs money

  • API / usage pricing = tokens in + tokens out
  • Long context windows mean more tokens per call
  • Multimodal input (image, audio, video) often costs more
  • High volume beats seat maths — model size × tokens dominates
  • Seats still matter for IDE tools (Copilot) and per-user chat plans

Note: we deliberately skip dollar figures here — pricing shifts monthly. Always check the vendor's current page before recommending a tier.

06 · Going Local

When you own the model, you own the ops

Local / self-hosted options — you own hosting, evals, and hardening. Flip the cards. "Open weights" spans everything from a laptop-sized model to a frontier-scale giant, so we cover both ends.

Hands-on

Self-hosting reality check: what does it actually take?

"Open source" doesn't mean "runs on anything." Parameter count roughly predicts the memory you need — click a size tier.

Rule of thumb: quantization (running the model at 4-bit or 8-bit precision instead of full 16/32-bit) shrinks memory needs by 2–4× for a small accuracy cost — it's often what makes "self-hosted" actually affordable. Typical stack as you scale up: Ollama / LM Studio on a laptop or single GPU to start → vLLM / TGI / TensorRT-LLM for production serving on rented GPUs → a managed inference API (the model's own, or a host like Together AI, Fireworks, or Groq) once you'd rather buy tokens than own hardware.

Bridge: this gets much deeper in the later SLM / local-AI curriculum modules — today is just enough to know when the option belongs on the table.

Wrap

Selection is a habit, not a one-time pick

Evidence over preference.

  • Four tools differ in ecosystem and best-fit jobs — not just "smarter / dumber"
  • Price seats and tokens — long context and multimodality change total cost of ownership
  • 5-factor framework + governance hard constraints = a defensible choice
  • Cloud vs. local and experiment vs. enterprise are policy / ops decisions
  • Switch mid-task with the same brief — don't tool-hop to shop for an answer
  • Highest lab score ≠ automatic production pick
